# Employee Performance Tracker

## 📌 Project Description
This is a full-stack web application to track employee performance, tasks, and productivity.

## 🚀 Features
- Add and manage employees
- Track performance data
- Backend API integration
- Database using Prisma & Railway

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript (or React if used)
- Backend: Node.js, Express
- Database: PostgreSQL (Railway)
- ORM: Prisma

## 📂 Project Structure
- frontend/
- backend/

## ▶️ How to Run
1. Clone the repo
2. Run `npm install`
3. Setup `.env`
4. Run `npm start`
